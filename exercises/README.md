# RAP Exercises

This folder contains practice exercises for learning and applying RAP (Reproducible Analytical Pipeline) principles in Python. Each exercise is self-contained and includes instructions, starter code, and tips for best practice.

## How to Use
- Work through each exercise in order, or choose based on your interests.
- Do not edit files in `src/` unless instructed by an exercise.
- Each exercise has its own subfolder and README.
- Solutions are not included; try to solve each exercise yourself!

## Exercises
- [01_add_module](01_add_module/README.md): Practice adding a new module to the pipeline.
- [02_unit_testing](02_unit_testing/README.md): Write and run unit tests for a module.
- [03_pre_commit](03_pre_commit/README.md): Set up and customize pre-commit hooks.
- [04_extend_pipeline](04_extend_pipeline/README.md): Extend the pipeline with a new feature or analysis.

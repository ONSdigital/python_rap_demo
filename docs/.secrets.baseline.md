# .secrets.baseline for python_rap_demo RAP project

This file is used by the detect-secrets tool to help prevent accidental commits of sensitive information (like passwords, API keys, or tokens) to your repository.
It contains a record of known secrets and the rules/plugins used to scan your codebase for new secrets.
When you run detect-secrets, it checks your code against this baseline and alerts you if it finds anything that looks like a secret.

## Why is this important?
- Protects your project and users from leaking sensitive data
- Supports reproducibility and security in RAP workflows
- Makes it easier to review and manage secrets in your codebase

## How do you use it?
- Run `detect-secrets scan > .secrets.baseline` to generate or update the baseline
- Run `detect-secrets pre-commit` before committing to check for new secrets
Or:
- Add .secrets.baseline as an argument to the detect-secrets section of `.pre-commit-config.yaml` (See file for an example)

If you intentionally add a secret, update the baseline and follow best practices for secret management
For more info, see https://github.com/Yelp/detect-secrets
